# Codemagic (Nevercode)

> Codemagic is a CI/CD platform for mobile app teams (Flutter, React Native, native iOS/Android, Unity, Ionic, .NET MAUI). Its REST API v3 manages applications, builds, artifacts, teams, secrets, over-the-air updates, and app previews.
